# Network Security Monitoring and Threat Detection System

The complete Flask SOC dashboard project is in [network_security_monitor/](./network_security_monitor/).

Open that folder in Visual Studio Code and follow its [README.md](./network_security_monitor/README.md) for the virtual environment, dependency installation, SQLite setup, run commands, and interview walkthrough.
